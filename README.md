📖 Sobre o Projeto
Tcf é uma aplicação web moderna desenvolvida para servir como material de apoio na apresentação do Trabalho de Conclusão Final. O projeto combina design responsivo, visualizações interativas e uma experiência de usuário fluída para engajar a audiência durante a demonstração do trabalho.

🔗 Repositório: https://github.com/THZIMX/Tcf

✨ Características Principais
🎯 Funcionalidades
🎨 Design Responsivo - Layout adaptável para projeção, desktop e dispositivos móveis

📊 Visualizações Interativas - Gráficos dinâmicos e componentes visuais com Recharts

⚡ Performance Otimizada - Carregamento rápido com Vite e code splitting

🎭 Animações Suaves - Transições elegantes usando Framer Motion

♿ Acessibilidade - Componentes acessíveis construídos com Radix UI

📱 Interface Moderna - Design limpo e profissional com TailwindCSS

🏗️ Arquitetura
Estrutura Modular - Componentes reutilizáveis e bem organizados

TypeScript - Tipagem estática para maior confiabilidade

Hooks Customizados - Lógica reutilizável e separada da UI

Roteamento Client-Side - Navegação fluida entre seções

🛠 Stack Tecnológica
Core
React 19 - Biblioteca principal para interface

Vite 6 - Build tool e dev server

React Router - Roteamento single-page application

Estilização & UI
TailwindCSS - Framework CSS utilitário

Radix UI - Componentes acessíveis e não-estilizados

Framer Motion - Biblioteca de animações

clsx - Composição condicional de classes

Visualização de Dados
Recharts - Biblioteca de gráficos e visualizações

Formulários & Validação
React Hook Form - Gerenciamento de formulários

Zod - Validação de esquemas TypeScript-first

🚀 Começando
Pré-requisitos
Node.js 18.0 ou superior

npm, yarn ou pnpm

Instalação
Clone o repositório

bash
git clone https://github.com/THZIMX/Tcf.git
cd Tcf
Instale as dependências

bash
npm install
# ou
yarn install
# ou
pnpm install
Execute em modo desenvolvimento

bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
Acesse a aplicação

Abra http://localhost:5173 no navegador

Scripts Disponíveis
bash
# Desenvolvimento
npm run dev          # Servidor de desenvolvimento
npm run build        # Build para produção
npm run preview      # Preview do build de produção
npm run lint         # Análise estática do código
